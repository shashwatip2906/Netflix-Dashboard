# Netflix Dashboard 

## About the Project

I created this dashboard in Tableau to explore Netflix's content and understand what its library looks like through data.

Netflix has a huge collection of movies and TV shows, and I wanted to turn that information into something visual and easy to understand. Instead of going through rows of data, this dashboard makes it easier to explore different aspects of the platform's content.

## What This Dashboard Covers

The dashboard explores Netflix's content across different categories, including:

- **Movies and TV Shows:** Understanding the distribution of content types.
- **Genres:** Exploring the different genres available on Netflix.
- **Release Year:** Looking at how content is spread across different years.
- **Countries:** Exploring the countries associated with Netflix titles.
- **Ratings:** Understanding the ratings assigned to different titles.

## Tools Used

- **Tableau** — for creating the dashboard and visualizing the data.
- **Netflix dataset** — as the data source for the analysis.

## Project Files

- `Netflix_Dashboard.twb` — The Tableau workbook containing the dashboard.
- `Netflix_Dashboard.pdf` — A PDF export of the dashboard for quick viewing.

## What I Learned

Working on this project gave me an opportunity to practice creating visualizations in Tableau and presenting data in a more understandable way. I also got to explore how different charts can help highlight patterns in a dataset.

This project is part of my journey toward improving my data analysis and visualization skills.

## How to View the Project

1. Download the `.twb` file from this repository.
2. Open it using Tableau Desktop.
3. If Tableau asks for the original dataset, connect it to the dataset used in the project.
4. Open the dashboard and explore the visualizations.

You can also check the PDF file to get a quick look at the dashboard without opening Tableau.
